================================================================================
RUNNING THE TESTS
================================================================================

QUICK START:
   1. cd e2e_tests
   2. pip install -r requirements.txt
   3. python app.py (in separate terminal from project root)
   4. pytest -v

COMMON COMMANDS:
   pytest                              # Run all 66 tests
   pytest -v                           # Verbose output
   pytest test_dashboard_ui.py         # Specific test file
   pytest -n 4 -v                      # Parallel execution (4 workers)
   pytest -x                           # Stop on first failure
   pytest -s                           # Show print statements
   pytest --html=report.html           # Generate HTML report
   pytest --cov=. --cov-report=html    # Generate coverage report
   pytest -m ui                        # Run UI tests only
   pytest -m api                       # Run API tests only

ARCHITECTURE
================================================================================

Test Structure:

       @pytest.fixture(autouse=True)
       def setup(self, driver, flask_app_server):
           self.page = CalendarDashboardPage(driver)
           self.page.navigate_to(flask_app_server)
       
       def test_something(self):
           # Arrange
           # Act
           # Assert

Browser Automation:
   - Browser: Google Chrome
   - Window Size: 1920x1080
   - Implicit Wait: 10 seconds
   - Explicit Wait: WebDriverWait(driver, 10)
   - Headless Mode: Configurable

Element Location Strategy:
   1. ID selectors (direct access)
   2. XPath (complex selection)
   3. CSS classes (Tailwind utilities)

Data Isolation:
   - Per-test database cleanup
   - Session via API creation
   - No test dependencies
   - Fresh database for each test
